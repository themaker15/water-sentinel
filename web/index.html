        1. น้ำปกติอย่างน้อย 3 session (เปลี่ยนน้ำ/คนละวัน) รวม 5 รอบขึ้นไป ยิ่งหลากหลาย เตือนผิดยิ่งน้อย
        2. ทุกรอบใช้ภาชนะ ระดับน้ำ และตำแหน่งหัววัดเหมือนเดิม · เปลี่ยนน้ำแล้วติ๊ก "เปลี่ยนน้ำใหม่แล้ว" รอบที่ใช้น้ำเดิมนับเป็น session เดียวกัน

        4. เทรนครั้งแรกด้วย normal อย่างเดียวได้ แต่ต้องมี anomaly จึงจะเปรียบเทียบโมเดลได้ครบ

        แต่ละสีคือหนึ่งรอบ · เส้นประ = เส้นเตือน (1.0) · น้ำปกติควรอยู่ใต้เส้น น้ำผิดปกติควรอยู่เหนือเส้น

        ROC curve

        ยิ่งโค้งเข้ามุมซ้ายบนยิ่งดี · AUC = 1 แยกได้สมบูรณ์ · 0.5 = เดาสุ่ม (ไม่ขึ้นกับการตั้งเกณฑ์)

        ข้อมูลจริงสองเซนเซอร์

        วงรี = ขอบเขตน้ำปกติของ MSPC (ประมาณในสองมิติ) · จุดนอกวงรีคือค่าที่ต่างจากน้ำปกติ

        ดูทีละรอบ: เปลี่ยนแปลงอย่างไรตามเวลา

        เส้นตั้งสีส้ม = เหตุการณ์ที่บันทึกไว้ (เช่นเติมสาร) · เส้นตั้งสีเทา = จุดที่ระบบตรวจพบว่าพฤติกรรมเปลี่ยน (change point) · แถบเหลือง = ช่วงเตือนล่วงหน้า (drift)

        เซนเซอร์ไหนทำให้ต่างจากน้ำปกติ

        สัดส่วน z² ของแต่ละเซนเซอร์ (MSPC) ณ แต่ละเวลา · ช่องว่าง = ยังอยู่ในช่วงน้ำปกติ

        เส้นทางของน้ำในระนาบ PCA

        จุดจาง = ต้นรอบ, จุดเข้ม = ท้ายรอบ · วงรี = ขอบเขตน้ำปกติ (โดยประมาณ)

        Dose-response: เติมเท่าไรระบบถึงเตือน

        ใช้รอบที่บันทึกเหตุการณ์ "เติมสาร" พร้อมปริมาณ · แกน x = ปริมาณสะสม · เส้นประ = เส้นเตือน · ปริมาณต่ำสุดที่จับได้อยู่ในคำอธิบายเส้น

        Embedding: PCA / t-SNE / UMAP

        ฉายข้อมูลหลายเซนเซอร์ลงสองมิติเพื่อดูว่าน้ำแต่ละแบบแยกกลุ่มกันไหม (ภาพเชิงคุณภาพ ใช้ประกอบการอธิบาย ไม่ใช่ตัวตัดสิน)
