      What the columns mean
      • Trend /min: outlier-resistant slope (Theil–Sen); close to 0 for normal water
      • noise: random jitter, measured from differences between consecutive readings (ignores slow drift); used to set the sensor floor
      • Settled after (s): seconds from the start of the run until the rolling mean stays within 1 floor of the final value · "not settled" = still drifting at the end of the run

        Suggested recording plan

        1. At least 3 sessions of normal water (fresh water or different days), 5 runs or more in total. The more varied, the fewer false alarms
        2. Use the same container, water level and probe position every run · after changing the water, tick "New water". Runs in the same water count as one session
        3. Anomaly runs, 3 min each: salt, baking soda, corn starch, hot water (and vinegar if you use pH)
        4. You can train on normal runs alone, but a full model comparison needs anomaly runs
